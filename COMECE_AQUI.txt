⚡ INÍCIO RÁPIDO (Windows)

   1. Certifique-se que Docker Desktop está instalado:
      https://www.docker.com/products/docker-desktop

   2. Clique duas vezes em:
      INICIAR_SISTEMA.bat

   3. Aguarde ~15 segundos

   4. Browser abrirá automaticamente

   5. Faça login com:
      Email: teste@example.com
      Senha: Teste123!

   ✅ Pronto! Sistema rodando!

══════════════════════════════════════════════════════════════════

📱 MOBILE/TABLET?

   Seu celular pode acessar se estiver na mesma rede:

   http://\[IP_DO_PC\]:3000

   Para descobrir o IP:
   Windows → ipconfig (procure por "IPv4 Address")
   Linux   → ip addr (procure por inet 192.168.x.x)
   Mac     → ifconfig (procure por inet)

✨ PRÓ-DICAS

   💾 Criar atalho na Área de Trabalho:
      Clique direito em INICIAR_SISTEMA.bat
      → "Enviar para" → "Área de Trabalho"
      Agora basta clicar no atalho para iniciar!

   🔑 Auto-iniciar na ligar PC (Windows):
      Abra Docker Desktop
      → Settings → General
      → Marque "Start Docker Desktop when you log in"

   🐳 Ver logs ao vivo:
      docker compose logs -f back
